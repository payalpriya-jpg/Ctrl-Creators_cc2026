# Ctrl-Creators_cc2026

One-Button Desi Arcade 🎮

A collection of fast, fun, and culturally inspired one-button mini games built using p5.js for the Creative Coding Hackathon 2026 under the “One-Button Games” theme.
This project combines simple controls with Indian-inspired gameplay, visuals, and arcade mechanics.

Games Included: 

🍥 Jalebi Stack

Stack hot crispy jalebis perfectly on top of each other without letting the tower collapse.
-> Features
• One-button timing gameplay
• Increasing difficulty
• Sweet shop themed visuals
• Local leaderboard using browser storage
• Win line challenge system

-> Controls
  Key                  Action
SPACEBAR             Drop Jalebi

🐎 Jungle Rush

Ride through a jungle road while avoiding wild animals and collecting diamonds.
-> Features
• Endless runner gameplay
• Dynamic obstacles
• Smooth lane switching
• Increasing game speed
• High score saving

-> Controls
   Key                 Action
LEFT ARROW            Move Left
RIGHT ARROW           Move Right
   "R"                Restart

🏏 One Button Cricket

A fast-paced cricket batting game where timing is everything.
-> Features
• One-button batting mechanic
• Dynamic bat swing animation
• FOUR and SIX effects
• Crowd animation
• Camera shake and particle effects
• High score system
• Wicket fall animation

-> Controls
  Key                  Action
SPACEBAR              Swing Bat
  "R"                 Restart
