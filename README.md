# ℹ️ Overview

**One-Button Desi Arcade** is a collection of mini-games created for the **Creative Coding Hackathon 2026** under the **One-Button Games** theme.

The project focuses on creating highly interactive gameplay experiences using minimal controls while keeping the mechanics fun, challenging, and visually engaging.

Each game explores a different gameplay style inspired by Indian culture and arcade mechanics:

- **Jalebi Stack** → Precision timing and balance
- **Jungle Rush** → Endless survival runner
- **One Button Cricket** → Fast reaction batting game

The project was developed using **JavaScript** and **p5.js** with a focus on animation, interaction, and game feel.

# 🎮 Games Included

---

## 🍥 Jalebi Stack

Stack jalebis perfectly on top of each other without collapsing the tower.

### Features

- One-button drop mechanic
- Increasing difficulty
- Sweet shop aesthetic
- Local leaderboard
- Win line challenge

### Controls

| Key | Action |
|------|--------|
| SPACEBAR | Drop Jalebi |

---

## 🐎 Jungle Rush

Ride through a jungle road while avoiding dangerous animals and collecting diamonds.

### Features

- Endless runner gameplay
- Random animal obstacles
- Collectible diamonds
- Increasing speed system
- Smooth lane movement

### Controls

| Key | Action |
|------|--------|
| LEFT ARROW | Move Left |
| RIGHT ARROW | Move Right |
| R | Restart |

---

## 🏏 One Button Cricket

Hit perfect cricket shots with timing-based controls.

### Features

- One-button batting mechanic
- FOUR and SIX visual effects
- Particle explosion effects
- Crowd animation
- Camera shake system
- Stump fall animation

### Controls

| Key | Action |
|------|--------|
| SPACEBAR | Swing Bat |
| R | Restart |
